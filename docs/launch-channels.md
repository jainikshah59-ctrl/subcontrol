Status: DRAFT — publish only where self-promotion is explicitly allowed. No spam, no fake reviews, no vote manipulation, no impersonation.

1. **Product Hunt** — schedule a launch day; needs account + maker verification (user action). Prep: tagline "Take Control of Every Subscription", 3 thumbnails, first comment with waitlist link.
2. **BetaList** — submit startup for pre-launch listing; free tier available, manual review.
3. **Indie Hackers** — share in "Launch" context with real numbers only; no fabricated traction.

## Tier 2 — communities (only where promotion is permitted)
4. **Reddit** — only subreddits that explicitly allow self-promotion and only with prior participation:
   - r/SideProject (self-promo friendly, follow their format)
   - r/productivity, r/personalfinance — check rules first; many ban promos. If in doubt, don't post.
5. **Hacker News** — "Show HN" only when there's something substantive to show; read the Show HN guidelines first.
6. **Dev.to / Medium** — build-in-public post about the waitlist + claymorphism build; not a pure ad.

## Tier 3 — social
7. **X (Twitter)** — new @subcontrol handle; build-in-public thread on launch day.
8. **LinkedIn** — founder post from the user's personal profile (higher trust than a brand page at this stage).
9. **Instagram** — 5-post sequence drafted in instagram-content.md.

## Rules of engagement (non-negotiable)
- Never claim user counts that don't exist ("20,000 users", "1,000 joined") — the site's social-proof counter stays hidden until real data exists.
- Never create fake testimonials or reviews.
- Never buy/manipulate votes or upvotes.
- Read each community's self-promotion rules before posting; when unsure, ask mods first.
- One genuine post per community; no cross-posting spam.

## Needs user action
- Product Hunt account + maker claim
- Reddit/HN accounts (or use existing personal ones)
